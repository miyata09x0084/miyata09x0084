- ### [kangeki_sbt](https://github.com/miyata09x0084/kangeki_sbt)

**お金に紐づかない感謝の気持ちを、社会的な価値に転換する「感謝の印」NFT です。**

スマートコントラクト上で譲渡不能な NFT（SBT）を発行する仕組みです。お金のために売買できないので、純粋な価値交換になります。Web3 で新しい社会価値を生む仕組みが作れないか、試したものです。
